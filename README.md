# Grundläggande grafteori

An interactive study guide to graph theory, written in Swedish while taking discrete mathematics at Mid Sweden University.

**[Open the live site](https://manwoodgrove.github.io/Grafteori/)**

Each concept is explained next to a small interactive graph you can drag around, so the definitions are tied to something you can see.

## Topics

- **General terms**: nodes, edges, graphs, neighbours
- **Node degree**: degree, in-degree and out-degree
- **Moving through a graph**: walks, trails, paths, circuits and cycles, with a step-by-step walk you can check
- **Complete and bipartite graphs**
- **Edge types**: directed, undirected, loops and multi-edges
- **Euler and Hamilton**: paths and circuits, with the conditions for when they exist
- **Permutations and combinations**: an interactive calculator that also lists the arrangements
- **Modelling examples**: real problems expressed as graphs

## Built with

Plain HTML, CSS and JavaScript with no build step. Graphs are drawn with [vis-network](https://visjs.github.io/vis-network/). Includes a dark mode.

To run it locally, open `index.html` in a browser.
